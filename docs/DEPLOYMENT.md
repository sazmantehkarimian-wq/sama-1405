# استقرار Windows/LAN

ZIP انتشار شامل Python 3.11 قابل‌حمل و پایگاه داده canonical ساخته‌شده از مراجع تأییدشده است؛ روی رایانه مقصد نصب Python یا اجرای ترمینال توسعه لازم نیست. ZIP را در یک مسیر محلی باز و `START_SAMA.bat` را اجرا کنید. در اجرای نخست شش حساب مصوب با گذرواژه‌های تصادفی ساخته می‌شوند؛ گذرواژه‌ها فقط در `FIRST_LOGIN_CREDENTIALS.txt` همان رایانه نوشته می‌شوند، تغییرشان در ورود نخست اجباری است و فایل باید پس از تحویل امن حذف شود.

نشانی محلی `http://127.0.0.1:8765/` و نشانی LAN برابر `http://SERVER-IP:8765/` است. برای Firewall ویندوز، یک Rule ورودی TCP برای پورت 8765 فقط از subnet سازمان تعریف کنید. متغیر `SAMA_PORT` پورت Start و Stop را هم‌زمان تغییر می‌دهد؛ در صورت تغییر، Rule فایروال نیز باید مطابق آن باشد.

`STOP_SAMA.bat` listener پورت تنظیم‌شده را متوقف می‌کند. داده، اسناد و secret محلی در پوشه `data` قرار دارند و نباید روی share عمومی ذخیره شوند.

## بازیابی کنترل‌شده

`python scripts/restore.py BACKUP_DIRECTORY` ابتدا manifest، SHA-256 همه فایل‌های رسانه، سلامت SQLite و کلیدهای خارجی را اعتبارسنجی می‌کند؛ سپس write lock سراسری می‌گیرد، پشتیبان pre-restore می‌سازد، DB و media را در staging آماده و به‌صورت atomic جایگزین می‌کند و سلامت نهایی را دوباره می‌سنجد. در هر خطا نسخه قبلی rollback می‌شود. اجرای بازیابی فقط برای مدیر سامانه و در پنجره نگهداری مجاز است.
