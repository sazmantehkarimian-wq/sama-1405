# تصمیمات مالک

- بنیان پاک و بدون reuse لایه‌های legacy؛ معماری modular monolith.
- **Operational Data در بسته تحویلی = صفر**؛ هیچ رکورد ملک، فضای تجاری یا سابقه عملیاتی از Excel وارد نمی‌شود.
- Excelها فقط مرجع ساختار فیلدها، قواعد و Validation هستند؛ **Import Excel/CSV در UI، API، CLI و Release وجود ندارد**.
- «کد فضا» Business Key یکتا و غیرقابل تغییر پرونده فضای تجاری است.
- «املاک مادر» یک دامنه مستقل است؛ ارتباط اجباری یا استنتاجی با کد فضای تجاری ممنوع است.
- حساب‌های مصوب فعلی ثابت می‌مانند.
- UI فارسی RTL، Vazirmatn محلی و navigation افقی؛ روش Portable LAN و پورت 8765 ثابت است.
- تاریخ کار عملیاتی جدید: ۱۴۰۵/۰۷/۰۱.
- Data Accuracy مقدم بر ظاهر است؛ مقدار ناقص یا مبهم حدس زده نمی‌شود.
- Export و چاپ مجاز است؛ ورود داده فقط از فرم‌های کنترل‌شده سامانه انجام می‌شود.

جزئیات اجرایی: `docs/ZERO_DATA_FOUNDATION.md`.
