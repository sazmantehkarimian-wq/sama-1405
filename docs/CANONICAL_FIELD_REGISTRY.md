# ثبت فیلد canonical

`CanonicalField` همه metadata مقرر را ذخیره می‌کند. importer هر heading را دقیقاً به یکی از MAPPED، DERIVED، REFERENCE_ONLY، DEPRECATED یا UNRESOLVED طبقه‌بندی می‌کند. ستون‌های reference/unresolved فقط در provenance قابل مشاهده‌اند و وارد UI عملیاتی با نام positional نمی‌شوند.
