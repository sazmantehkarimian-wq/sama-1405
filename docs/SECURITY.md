# امنیت

Django PBKDF2 password hashing، CSRF، session HttpOnly/SameSite، clickjacking protection، permission decorators، محدودیت extension/size آپلود و throttling پنج‌دقیقه‌ای ورود فعال‌اند. `scripts/first_start.py` گذرواژه‌های تصادفی را فقط در فایل محلی یک‌بارمصرف می‌نویسد؛ تغییر در ورود نخست اجباری است و هیچ گذرواژه‌ای در Git یا log ساخت قرار نمی‌گیرد. hard delete عمومی endpoint ندارد و archive/cancel/state transition مسیرهای عادی هستند.
