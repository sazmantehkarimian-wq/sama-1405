# مبنای قطعی Zero-Data سما

این سند تصمیم مالک برای بازطراحی مسیر ورود اطلاعات سما را ثبت می‌کند.

## قواعد قطعی

1. پایگاه داده عملیاتی در بسته تحویلی صفر رکورد املاک، فضای تجاری، قرارداد، بهره‌بردار، کارشناسی، مزایده، سند، گردش پرونده و Timeline دارد.
2. هیچ مسیر Import از Excel/CSV در UI، API، CLI یا بسته LAN وجود ندارد.
3. فایل‌های Excel فقط مرجع استخراج ساختار فیلد، قواعد و Validation هستند و داده‌های آنها وارد سامانه نمی‌شوند.
4. «کد فضا» Business Key یکتا و غیرقابل تغییر پرونده فضای تجاری است و تمام سوابق عملیاتی فضای تجاری به آن متصل می‌شوند.
5. «املاک مادر» دامنه مستقل است و هیچ رابطه اجباری یا استنتاجی با کد فضای تجاری ندارد.
6. حساب‌های مصوب و روش اجرای Portable LAN روی پورت 8765 ثابت می‌مانند.
7. ورود داده فقط از فرم‌های کنترل‌شده و سرویس‌های دامنه مجاز است.
8. Validation هم در Server و هم در Database/Domain اعمال می‌شود؛ اعتبار تاریخ شمسی، محدوده عددی، یکتایی، روابط و State Transition نباید فقط به UI وابسته باشد.
9. Export/Print مجاز است؛ Import ممنوع است.
10. هیچ داده نمونه یا Fixture در بسته LAN قرار نمی‌گیرد.

## معیار پذیرش پایه

- اجرای migration روی پوشه data خالی موفق باشد.
- پس از migration و قبل از ورود کاربر، شمار رکوردهای عملیاتی صفر باشد.
- هیچ ماژول import_pipeline و هیچ دستور import در Release وجود نداشته باشد.
- اولین رکورد عملیاتی فقط با اقدام صریح کاربر ساخته شود.
- نسخه UAT/LAN تا عبور از تست واقعی و پذیرش Owner، Production-ready اعلام نشود.
