# سما — UI/UX Frozen 1405

وضعیت: **FROZEN پس از پذیرش انسانی مالک**. تا قبل از پذیرش انسانی، این سند مبنای UAT بصری است و پس از پذیرش، تغییرات صفحه‌ای خارج از Design System مجاز نیست.

## هویت

- نام محصول در UI فقط «سما» است.
- بلوک هویت کنار لوگوی رسمی، سه خط وسط‌چین دارد: «سما»، «مدیریت اقتصادی و املاک»، «اداره املاک و مستغلات».
- فایل لوگوی رسمی بدون بازطراحی، تغییر رنگ، نسبت یا افکت استفاده می‌شود.
- فونت UI: Vazirmatn محلی و آفلاین؛ تفاوت سلسله‌مراتب با وزن و اندازه انجام می‌شود.

## پالت و رنگ

تمام رنگ‌ها فقط از `design_system/static/design_system/css/tokens.css` مصرف می‌شوند. افزودن رنگ صفحه‌ای یا hex مستقل در Template/CSSهای صفحه ممنوع است.

خانواده‌های معنایی موجود:

- neutral: سطح، متن، حاشیه و پس‌زمینه
- brand: هویت اصلی
- success: موفق/فعال
- warning: هشدار
- danger: خطا/خطر
- info: اطلاعات
- domain accents: داشبورد، املاک مادر، فضاهای تجاری، قرارداد، کارشناسی، مزایده، انشعابات، گردش پرونده، اسناد، پیگیری، گزارش و کاربران

رنگ دامنه فقط در accent، active state، badge، خط عنوان، KPI و highlight محدود استفاده می‌شود؛ کل صفحه رنگی نمی‌شود.

## تراکم و کنترل‌ها

- UI هدف: compact professional؛ نه متراکم آزاردهنده و نه کنترل‌های بزرگ.
- Row action حدود 28–30px.
- کنترل عادی حدود 32px.
- Primary حدود 34–36px و فقط در صورت نیاز بزرگ‌تر.
- Full-width button فقط با دلیل UX روشن.
- جدول‌ها ردیف‌های فشرده، header واضح، hover ملایم و ستون عملیات باریک دارند.

## پرونده‌ها

پرونده فضای تجاری و ملک مادر Read-focused هستند:

1. Summary Hero
2. Facts مهم در یک نگاه
3. Tabs فشرده
4. Section cardهای خواندنی
5. عملیات از طریق workspace تخصصی

فرم‌های بزرگ چندحوزه‌ای داخل پرونده ممنوع است.

## مناطق و مراکز

`مناطق و مراکز` یک لایه Navigation/Aggregation روی داده canonical است؛ دیتای موازی ایجاد نمی‌کند.

- انتخاب مناطق 1 تا 22 به‌صورت grid
- مراکز خاص مستقل از مناطق عادی
- منطقه جغرافیایی مرکز خاص فقط context تحلیلی است
- KPIها باید به رکورد دقیق drill-down شوند
- رکوردها نباید در گروه مدیریتی دوباره‌شماری شوند

## گزارش و چاپ

- چاپ صفحه برای صفحات احراز هویت‌شده به‌صورت مرکزی در دسترس است.
- گزارش رسمی همچنان از موتور مرکزی PDF/XLSX/DOCX تولید می‌شود.
- ستون خالی و ردیف خالی فقط در خروجی‌اند و DB را تغییر نمی‌دهند.
- املاک مادر و فضاهای تجاری هر دو در Report Builder مرکزی حوزه مستقل‌اند.
- ترتیب، فیلتر، sort، orientation و blank rows باید در خروجی حفظ شوند.

## Picker و Overlay

Single-select picker پس از انتخاب بسته می‌شود؛ Enter انتخاب می‌کند و می‌بندد؛ Escape و click-outside می‌بندند؛ انتخاب قبلی حفظ می‌شود.

## Guardrails

- بدون runtime CDN.
- بدون inline style در Template.
- بدون CSS صفحه‌ای خارج از Design System.
- بدون Sidebar دائمی.
- بدون بازطراحی معماری یا frontend stack.
- خروجی‌های رسمی فاقد نام سما و SMK هستند.

## مسیر تغییر آینده

هر تغییر بصری پس از Freeze باید ابتدا در Token/Component مشترک تعریف شود و Regression Visual/Browser را پاس کند؛ patch صفحه‌ای مجاز نیست.
